Daisy-chaining Pavlovia and Qualtrics
=====================================

Sometimes you may want to run part of your experiment on Qualtrics (e.g., questionnaires) and part in PsychoPy/Pavlovia (e.g., behavioral tasks). This is often called **daisy-chaining** experiments.

This page provides guidance and resources for setting up such workflows.

Overview
--------

Daisy-chaining typically involves:

1. Starting participants in Qualtrics
2. Redirecting them to a Pavlovia experiment
3. Returning them to Qualtrics (if needed) to complete surveys or record responses

Resources
---------

- YouTube tutorial: `Qualtrics → Pavlovia → Qualtrics workflow <https://www.youtube.com/watch?v=SAbKAz4M-Rg>`_  
- PsychoPy forum discussion: `Qualtrics to PsychoPy back to Qualtrics <https://discourse.psychopy.org/t/qualtrics-to-psychopy-back-to-qualtrics/27617/15?u=becca>`_


Recommended alternative: Pavlovia Surveys
--------------------------------------------

For many use cases, we recommend using **Pavlovia Surveys**.  

- Pavlovia Surveys allows you to import `Qualtrics QSF` files directly.  
- This can simplify your workflow and reduce the need for multiple redirects.  
- Video tutorials for Pavlovia Surveys: `YouTube playlist <https://www.youtube.com/watch?v=bTaEqN2ZKpE&list=PLJVOIgS89ZnP5ajKzFyNaALehRTF2eDOv>`_
